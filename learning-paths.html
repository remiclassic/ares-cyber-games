Where the games plug into the nine full-release paths

Ares has no written curriculum. Its structure is the learning paths in Studio. Nine of the 71 paths are marked Full release and licensed to every customer. This page places a game at each point in those paths where the learner has to make a decision, and sets out what the platform needs from each game to track it like other content.

What the platform gets from every game

Brad's three asks, answered with one shared message contract. Every game already runs in an iframe and talks to its host over postMessage. These messages go into one shared module, so all 36 games behave the same way.

01 · Attempts

Report start to stop

attempt-started when Start is pressed. attempt-ended with a reason: completed, milestone, stopped by the platform, learner quit, or timeout. Closing the tab still ends the attempt. Each retry is a new attempt.

Today: games report started, actions and completed. Quit and stop are not reported yet.

02 · Start at a level

Platform chooses the entry point

host:init carries startAt, a levels subset, the seed, practice or assessed mode, and the course context. Each game lists its level IDs in ready, so Studio authors pick from a list.

Today: course context is hard-coded mock text, and seeds work.

03 · Stop at a milestone

Interrupt when the goal is met

stopWhen takes a milestone, a score or a number of minutes. The game finishes the current step, shows a short debrief and reports reason: "milestone". host:stop ends the game immediately, for example when the range is ready.

Today: only Alert or Noise and Breach Timeline listen for stop.

Found in Studio: a Minigame item type already exists, but it is a placeholder

Studio lists Minigame next to Mission, Knowledge Check, Exam, PDF and Video. The new-item form asks only for a title and a description: there is no field for the game's URL, its settings or attempt tracking. The one draft, "Mini-game 1" from March 2026, is in no path. The integration work is to define what a Minigame item carries. The three asks above are that definition.

Two shapes of path, two places for a game

Concept paths · video → PDF or knowledge check pairs, then an exam. The game goes after each pair, so the idea is used before it is tested Mission paths · a run of range missions. The game goes before the mission to rehearse its decision, and short modes fill range spin-up

New game worth building: "Read the Packet"

All nine Networking Hands-on Labs, Defensive Cyber 1.0 and Digital Forensics 1.0 ask the learner to find one detail in a packet capture. No game rehearses that yet. It is the clearest gap in the catalog.

Leave alone for now

Advanced Networking Protocols covers STP, OSPF, IS-IS and BGP, which is network engineering. Only Port Authority fits, at TLS and SNMP, so it is not a pilot path.
